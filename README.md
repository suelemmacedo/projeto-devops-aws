# Projeto DevOps AWS — Docker e Terraform

Este repositório reúne dois laboratórios práticos desenvolvidos durante meus estudos em DevOps, com foco em conteinerização, serviços AWS e Infrastructure as Code (IaC).

O projeto foi desenvolvido com base nas aulas da **Maria Lázara**, permitindo colocar em prática conceitos de infraestrutura, automação e gerenciamento de recursos em nuvem.

## Objetivo

Explorar a evolução de um ambiente DevOps, começando pela criação e execução de contêineres Docker na AWS e avançando para o provisionamento de infraestrutura utilizando Terraform.

## Tecnologias utilizadas

- **Docker:** criação e execução de contêineres.
- **Amazon EC2:** hospedagem da aplicação.
- **Amazon ECR:** armazenamento de imagens Docker.
- **Terraform:** provisionamento e gerenciamento de infraestrutura como código.
- **AWS Security Groups:** configuração de regras de acesso à infraestrutura.
- **Git e GitHub:** versionamento, documentação e gerenciamento do código.
- **Linux:** ambiente utilizado durante o desenvolvimento dos laboratórios.

## Parte 1 — Docker e AWS

Na primeira etapa, o objetivo foi compreender o processo de conteinerização de uma aplicação web e sua execução em uma instância Amazon EC2.

As atividades envolveram a criação de um Dockerfile, construção de imagens Docker, execução de contêineres, configuração de portas e utilização do Amazon ECR.

**[Acessar documentação da Parte 1](parte1-docker/README.md)**

## Parte 2 — Terraform e AWS

Na segunda etapa, o foco foi Infrastructure as Code (IaC), utilizando Terraform para definir e gerenciar recursos na AWS.

Durante o laboratório, foram trabalhados o provisionamento de instância EC2, a criação de repositório ECR, a configuração de Security Groups e os principais comandos do Terraform.

**[Acessar documentação da Parte 2](parte2-terraform/README.md)**

## Aprendizados

Esses laboratórios contribuíram para fortalecer meus conhecimentos em Docker, AWS, Terraform, Linux e Git.

Também permitiram compreender melhor como as práticas de conteinerização e infraestrutura como código se complementam no contexto DevOps.
